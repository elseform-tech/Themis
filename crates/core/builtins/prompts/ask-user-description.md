Ask the user a question without stopping your work. Use it when you need their input or a decision only they can make. Always give your answer in `recommended`: with 2 to 4 `choices` when the answer is one of a few options (your recommended one among them), or alone as your suggestion when the answer is open (a name, some wording). Keep working on your recommendation until they answer: the question shows in the chat and the user can answer whenever they like; the answer reaches you as a message. Set `blocking` only when nothing more can be done toward the request without the answer; then the run ends and waits for them. Ask about one thing per question, and reuse the same `topic` to update a question that is still open instead of asking it again.
