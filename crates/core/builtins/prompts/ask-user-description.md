Ask the user a question without stopping your work. Use it when you need their input or a decision only they can make. Say in `assumption` what you will assume until they answer, then keep working on that assumption: the question shows in the chat and the user can answer whenever they like; the answer reaches you as a message. Set `blocking` only when nothing more can be done toward the request without the answer; then the run ends and waits for them. Ask about one thing per question, offer `choices` when the answer is one of a few options, and reuse the same `topic` to update a question that is still open instead of asking it again.
