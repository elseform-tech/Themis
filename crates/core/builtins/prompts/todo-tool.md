Your to-do list. Send the whole list each time; it replaces the one before. Each item has a `title`, optional `details` (what done means and the specifics), a `status` (pending, in_progress or completed) and, once completed, an optional one-line `outcome`. Pass an item's `id` to keep it; an item sent with its id and without `details` keeps the details it has, and a request of the person's keeps their words. The person sees the list.
