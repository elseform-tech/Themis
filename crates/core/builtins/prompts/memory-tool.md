Your memory across chats, kept by Themis outside the project. Actions: "save" a new memory, "update" one by name (give every field again), "delete" one, "read" one in full. A memory is one fact with a kebab-case name, a one-line description and a type: "user" (about the person), "feedback" (how they want work done), "project" (facts about this project) or "reference" (where to find things outside it). For feedback and project memories add why and how_to_apply. Scope is "project" unless you say "global"; only user and feedback memories may be global, and a global memory holds nothing specific to one project (no paths, repository or client names, code). When a memory is built from a web page or a file rather than from the person, set source to say which. Secrets are removed before saving.
