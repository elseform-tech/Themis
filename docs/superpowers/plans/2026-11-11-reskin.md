# Reskin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the existing screens the canvas's look: retire Bubbles, set the new rail order, frame
the layout in Classic, then add the Morning, Noon and Night sky themes and an Auto option that
follows the time of day.

**Architecture:** This is front-end work in `web/src`, plus three small backend touches: the
palette allow-list in `crates/desktop/src/settings.rs`, and the companion window in
`tauri.conf.json` and `lib.rs`. The layout ships first in Classic, which is today's palette. The
sky themes come after a measured Linux performance check of `backdrop-filter`, and they have a
solid fallback with no blur.

**Tech Stack:** React 18 + TypeScript, Vitest (jsdom), plain CSS tokens, Tauri 2, Rust.

**Spec:** docs/superpowers/specs/2026-11-11-visions-design.md (decisions table: rail, Chats default,
sidebar toggle in the top bar, Bubbles retired; "Separate track" paragraph). Design canvas:
https://claude.ai/artifact/JZgtvsAnv7iiDQUmE7zjqq, boards Loading, Chat, Chat with Workspace, Chat
while streaming, Integrations, Automations, Settings.

## Global Constraints

- Every visible word and control must earn its place (DESIGN.md "Only what earns its place").
- Built-in features work the same on macOS, Windows and Linux. No OS-only substitutes.
- Text contrast is at least 4.5:1, large text at least 3:1, and control and focus edges at least
  3:1, in every preset, measured on the actually rendered colours.
- Motion respects `prefers-reduced-motion`.
- Ratchets: files ≤ 1000 code lines, functions ≤ 100 lines, cognitive ≤ 25, cyclomatic ≤ 20.
  Entries in `quality_dashboard/ratchets_baseline.json` may only shrink. Splitting a listed
  function is a refactor: one per PR, behaviour unchanged.
- One PR per task below, each on its own `codex/<name>` branch from fresh `main`. Each PR is
  verified in the real app, and screenshots go in the PR.
- No backward-compatibility shims. Removed things are removed, and the PR says what breaks.

## Review Focus

1. **A saved palette id that no longer exists** (for example, someone on a removed or renamed
   preset): the app must open with Classic, not a blank or broken theme. Owner: Task 5, test
   `appearancePreset falls back to classic for unknown ids`.
2. **Sky themes where `backdrop-filter` is unsupported or slow** (WebKitGTK on Linux): panels must
   be solid and readable, never see-through without blur. Owner: Task 5, test
   `glass falls back to solid panels when backdrop-filter is unsupported`.
3. **Auto crossing a boundary while the app is open** (07:00 or 19:00): the theme changes without a
   reload, and it does not flicker on every tick. Owner: Task 6, test
   `auto switches once at the boundary`.
4. **The startup loader after Bubbles is gone:** a failed start still shows the error state and
   the "Loading preferences" / "Opening workspace" status text. Owner: Task 1 (the existing
   `Workspace.test.tsx` checks around L352-383 move to the new loader).
5. **Narrow windows with the framed layout** (1024 px wide, Workspace open): the sidebar still
   folds automatically below 1500 px (`App.tsx:40`), and nothing overflows. Owner: Task 4, test
   `framed layout keeps auto-fold below 1500px`.
